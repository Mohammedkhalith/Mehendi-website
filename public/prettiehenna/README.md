# PrettieHenna

## Overview
PrettieHenna is a beautifully designed e-commerce platform dedicated to showcasing and selling henna artistry products. The website features a main landing page that highlights services, testimonials, and contact information, as well as a dedicated shop page for browsing and purchasing products.

## Project Structure
```
prettiehenna
├── index.html        # Main landing page showcasing henna artistry services
├── shop.html         # E-commerce page for browsing and purchasing products
├── style.css         # Main styles for the landing page
├── shop.css          # Styles specific to the shop page
├── script.js         # JavaScript for main website functionalities
├── shop.js           # JavaScript for e-commerce functionalities
├── assets
│   └── fonts         # Directory containing font files for typography
├── README.md         # Documentation for the project
└── .gitignore        # Files and directories to be ignored by version control
```

## Features
- **Landing Page**: Engaging design that showcases henna artistry services, including an about section and testimonials from satisfied clients.
- **E-commerce Functionality**: A dedicated shop page with a product grid, filters, and a shopping cart that retains items even after refreshing the page.
- **Responsive Design**: The website is designed to be fully responsive, ensuring a seamless experience on both desktop and mobile devices.
- **Interactive Elements**: Includes animations, toast notifications for cart actions, and a product detail modal for enhanced user experience.

## Setup Instructions
1. Clone the repository to your local machine.
2. Open `index.html` in your web browser to view the landing page.
3. Navigate to `shop.html` to explore the e-commerce features.
4. Ensure that all assets, including fonts, are correctly linked in the HTML files.
