# 🌿 PwrettieHenna

PwrettieHenna is a modern henna website designed for customers to explore henna services, view designs, book henna sessions, and purchase henna-related products.

## ✨ Features

- Henna service booking
- Bridal henna designs
- Henna product showcase
- Customer reviews
- Henna gallery
- Henna care and aftercare information
- Responsive design for mobile and desktop
- Contact / booking form
- Modern animations and interactive effects

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Node.js
- Vercel
- Formspree

## 📂 Project Structure

🚀 Deployment

This website is deployed using Vercel.

After updating the code and pushing the changes to GitHub, Vercel can automatically rebuild and deploy the latest version of the website.
